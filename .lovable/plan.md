## 목표
ElevenLabs로 만든 양치기 소년 MP3 음성 파일들을 스토리 재생과 무관하게 **바로 골라 들을 수 있는 오디오 브라우저 페이지**를 추가합니다.

## 페이지
- 새 라우트: `/audio` (`src/routes/audio.tsx`)
- 메인 화면(카세트 목록)에서 접근할 수 있는 "🎧 음성 듣기" 버튼 하나 추가
- 모바일 우선 세로 리스트 UI, 다크 톤 유지

## 화면 구성
1. **씬 마스터 (12개)**
   - `scene1.mp3` ~ `scene12.mp3` 각각 재생 버튼 + HTML5 `<audio controls>`
   - 파일 크기 / 길이(로드 후) 표시
2. **씬별 개별 대사**
   - 씬을 아코디언으로 접었다 펼치기
   - 각 씬의 `scene<N>/tts/*.mp3` 파일을 파일명(예: `04_tom.mp3`) + 화자 배지와 함께 나열
   - 각 항목마다 재생/일시정지 + `<audio controls>` + 다운로드 링크

## 데이터 소스
- 파일 목록은 하드코딩하지 않고, `boy-wolf` `script.json` + `timing.json`을 로더에서 읽어 씬/라인/화자/대사 텍스트를 함께 표시
- 마스터 파일 존재 여부는 URL 규칙(`/audio/boy-wolf/scene<N>.mp3`)으로 처리, 실패 시 항목 숨김

## 재생 동작
- 한 번에 한 개만 재생: 새 항목 재생 시 이전 오디오 자동 일시정지
- 스토리 재생 로직(`useSceneMasterVoice` 등)과 완전히 분리 — 이 페이지는 순수 `<audio>` 요소만 사용해 재생 안정성 이슈 회피
