---
name: 동화 씬 제작 원칙
description: 모든 동화에 적용할 90초 씬 구조, 오디오 컷, 전환 안정성 원칙
type: feature
---
동화 씬은 항상 90초 단위로 구조화한다.

- BGM/SFX 파일이 입력되면 앞부분 90초만 사용하는 기준으로 적용한다. 파일이 더 길어도 씬에서는 90초 지점에서 처음으로 돌아가거나 다음 씬 전환 시 정지/초기화되어야 한다.
- 각 씬은 배경, 캐릭터, 모션, 대사, 나레이션, BGM, SFX를 하나의 결정적 타임라인으로 묶는다.
- 다음 씬으로 넘어갈 때 이전 씬의 오디오/모션 상태가 남지 않도록 트랙 currentTime을 0으로 되돌리고 pause/cleanup을 보장한다.
- 재생/2배속/일시정지 설정은 BGM/SFX/모션 타임라인에 동일하게 반영되어야 하며, 수정이나 커밋 후에도 자동 실행 설정이 바뀌면 안 된다.
- 씬 완료 콜백은 90초 도달 시 한 번만 호출한다. 루프나 렌더 재시작으로 중복 전환이 발생하면 안 된다.
- 이 원칙은 현재 개미와 베짱이뿐 아니라 이후 제작하는 다른 모든 동화에도 기본 규칙으로 적용한다.
