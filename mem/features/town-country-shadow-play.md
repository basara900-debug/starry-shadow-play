type: feature
---
새 그림자 연극 카세트 `시골쥐와 서울쥐`는 5개 씬으로 구성한다.

- 씬 1: 시골 풍경
- 씬 2: 서울쥐 집안
- 씬 3: 식당
- 씬 4: 복도
- 씬 5: 시골쥐 집안

- 배경 이미지는 사용자가 올린 순서를 그대로 사용한다.
- 씬 길이는 고정하지 않는다. 각 씬의 대사/나레이션 분량이 정해지면 그에 맞춰 산정한다.
- 전체 대사, BGM, SFX는 나중에 사용자 첨부본으로 교체할 수 있도록 씬별 슬롯을 비워 둔다.
- 대사가 들어오기 전까지는 임의 자막을 화면에 생성하지 않는다.
- 마지막 씬이 끝나면 메인 타이틀 UI로 복귀한다.
