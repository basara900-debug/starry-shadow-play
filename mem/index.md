# Project Memory

## Core
불변 규칙 1 — 타이틀 UI(퍼스트 스테이지)는 카세트 플레이어 컨셉이며 불변. 개발자(사용자)와 협의 없이는 절대 변경 금지.
불변 규칙 2 — 앱은 투스테이지 구조. 퍼스트=타이틀 카세트 UI, 세컨드=그림자 연극 레이블 스테이지. 모든 기능은 이 구조 안에서만 동작.
플레이 토글(퍼스트→세컨드) 동시성: (a)버튼 눌림 애니메이션 +(b)클릭 SFX +(c)커튼 열림 시작 +(d)토끼·다람쥐 점프 +(e)BGM 페이드아웃, 모두 동시에 시작되고 시퀀스 완료 후 전체 화면 전환.
세컨드→퍼스트 복귀: 연극 슬라이더 엔딩 도달 또는 나가기 → 전체 화면 전환 → 커튼 닫힘 → 별똥별 → 아이들 상태 유지.
세컨드 스테이지는 자체 컨트롤 패널(재생/일시정지/나가기/설정/슬라이더) 보유. 타이틀 UI 컨트롤과 분리.
카세트 교체(스토어에서 구매한 동화 카세트를 인풋·이젝트·리스트 선택) 메커니즘은 핵심 수익 모델이며 변질 없이 구현.
좌측 원형 창 = 별 반짝임/나무 윗부분 흔들림/별똥별. 우측 원형 창 = 동물 친구 움직임/커튼 움직임. 헷갈리지 말 것.
