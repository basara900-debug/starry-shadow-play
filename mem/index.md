# Project Memory

## Core
캐릭터 시트(인물/동물 컷아웃) 이미지는 항상 투명 PNG로 처리 후 적용. 원본에 종이/그리드/단색 배경이 있어도 imagegen edit_image의 transparent_background=true로 배경 제거 뒤 사용.
동화 씬은 90초 단위로 배경/캐릭터/모션/대사/나레이션/BGM/SFX가 함께 결정적으로 전환되어야 한다.
사용자가 올린 대사/나레이션 텍스트는 절대 임의로 수정·요약·재작성하지 않는다. 문장부호·띄어쓰기·오탈자까지 원문 그대로 유지하고, 빈 구간을 임의 문장으로 채우지 않는다(빈 칸은 빈 칸으로 둔다).
